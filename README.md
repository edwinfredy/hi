This is my personal website, deployed at [edwinfredy.com](https://edwinfredy.com).

## Development

Install dependencies and start the Vite development server:

```sh
npm install
npm run dev
```

Create a production build in `dist/` with `npm run build`, or preview it locally
with `npm run preview`.

The site is a React app built with Vite. GitHub Actions builds it and deploys
`dist/` to GitHub Pages when changes are pushed to `main`.
