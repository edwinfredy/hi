This is my personal website, deployed at [edwinfredy.com](https://edwinfredy.com).

## Development

Install dependencies and start the Vite development server:

```sh
npm install
npm run dev
```

Create a production build in `dist/` with `npm run build`, or preview it locally
with `npm run preview`.

The site is a React and TypeScript app built with Vite. Run `npm run typecheck`
to check types, or `npm run build` to type-check and create the production
bundle. GitHub Actions deploys `dist/` to GitHub Pages when changes are pushed
to `main`.
